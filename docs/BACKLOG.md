# Бэклог Karabas Board Test

## Открытые вопросы
- Бюджет BRAM (Ф0): влезут ли код 32–48 КБ, два атласа шрифтов и экран в 52 RAMB16.
- Частота CLK_50 относительно MCU: чем мерить со стороны прошивки (RPC SYS?).

## Ошибки
- Логотип всегда «Karabas MiniGO» (`logo_full` из `ui2.c` прошивки), на любой плате: брать логотип платы по HW_ID из RPC `SYS INFO` (Go / Mini / Mini G; пользователь 2026-11-22, замечено на Go).

## Позже
- Go: страница I2C (RTC / EEPROM) должна явно говорить, что расширитель PCA9536 (0x41) не отвечает и поэтому кнопки и LED платы не работают. 2026-11-22 у пользователя на Go чип с AliExpress, видимо брак: в скане только 50–57 и 68, а прошивка пишет `PCA9536 unavailable`.
- Отчёт прогона через USB CDC (машиночитаемый, для стенда без экрана) — не в Ф4 (пользователь 2026-11-22).
- Картинка FT812 через FT_DE / FT_CLK (Mini, Mini G; Go — свой путь): список отображения из CPU + выбор видео FT в `hdmi_top` (пользователь 2026-11-22: не в Ф3).
- Полноэкранные тестовые картинки из SRAM после прохода её теста (полосы, градиенты по битам ЦАП, сетка).
- Тест записи на SD2 / CF в отдельной области — только если пользователь укажет носитель.
- Проверка на платах Go и Mini (Floppy — на Go с дисководом).
- Шилд Mini G (CF и прочее на нём).
